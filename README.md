# MCP-Jamovi
Repositorio dedicado a la implementación de un servidor MCP para jamovi.

Estado actual
- Fase: definición y preparación de base técnica.
- Prioridad: documentación, contenedorización y esqueleto del servidor.

Enfoque inicial
- Python 3.10+ como runtime del servidor.
- Docker como capa de aislamiento.
- Transporte MCP por stdio en la primera entrega.
- Integración con R para lectura de datasets y análisis descriptivos.
