SPEC-004: Expansion del Catalogo Estadistico (T-Tests y Correlacion)1. ObjetivoDefinir la interfaz de herramientas MCP para analisis mas alla de los descriptivos, asegurando paridad con los argumentos de la libreria jmv de R.2. Herramientas a ImplementarA. jmv_ttestIS (Prueba T para muestras independientes)Funcion R: jmv::ttestISArgumentos Requeridos:vars: List[str] (Variables dependientes).group: str (Variable de agrupacion, factor con 2 niveles).Argumentos Opcionales:welchs: bool (Default: true).norm: bool (Prueba de normalidad Shapiro-Wilk).eqv: bool (Prueba de homogeneidad de varianzas).B. jmv_corrMatrix (Matriz de Correlacion)Funcion R: jmv::corrMatrixArgumentos Requeridos:vars: List[str] (Variables a correlacionar).Argumentos Opcionales:pearson: bool (Default: true).spearman: bool (Default: false).sig: bool (Mostrar significancia).3. Validacion de EsquemaCada herramienta debe utilizar un modelo Pydantic en models.py que herede de un BaseAnalysisModel para asegurar que dataset_path este siempre presente.4. Restricciones de EjecucionEl servidor debe validar que las columnas existan en el data.frame cargado antes de invocar a R.Si group tiene mas de 2 niveles, el servidor debe interceptar el error de R y sugerir el uso de ANOVA.
