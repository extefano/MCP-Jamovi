SPEC-005: Logica de Serializacion de Resultados (R6 a JSON/Markdown)1. El Problema de los Objetos R6Las funciones de jmv devuelven objetos R6 que contienen metadatos, tablas y graficos. El puente rpy2 no puede serializar estos objetos directamente a JSON.2. Protocolo de Extraccion (Core Logic)Para cada objeto de resultados (res), el r_bridge.py debe implementar la siguiente secuencia de extraccion:Iteracion de Elementos: Recorrer res$items.Identificacion de Tablas: Si el item es una tabla:Convertir a data.frame usando item$asDF.Transformar el data.frame de R a un diccionario de Python/Pandas.Manejo de Notas: Extraer item$notes para capturar advertencias estadisticas (ej. "La prueba de normalidad sugiere desviacion").Formateo de Salida:Generar un bloque Markdown legible para el LLM.Incluir una version estructurada en JSON para procesamiento programatico.3. Manejo de Errores en el PuenteSi la ejecucion de R falla, el r_bridge debe capturar el mensaje de error y buscar palabras clave:is not a factor: Traducir a "La variable X debe ser nominal u ordinal".not enough observations: Traducir a "N insuficiente para el analisis solicitado".
