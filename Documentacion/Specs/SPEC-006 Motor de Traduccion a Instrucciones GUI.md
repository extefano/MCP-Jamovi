SPEC-006: Motor de Traduccion a Instrucciones GUI (Instruction Engine)1. PropositoCumplir con el requerimiento de generar guias paso a paso para la interfaz grafica de jamovi basadas en la llamada a la herramienta MCP.2. Logica de Mapeo (Static Mapping)El servicio GUITranslator debe contener un mapa de definiciones basado en los archivos .u.yaml de jamovi.Ejemplo de Mapeo para jmv::descriptives:tool_name: jmv_descriptivesmenu_path: "Analyses -> Exploration -> Descriptives"param_map:vars: "Variables" (TargetLayoutBox)splitBy: "Split by" (VariablesListBox)freq: "Frequency tables" (CheckBox)3. Generacion de TextoEl output debe seguir este patron:"Para replicar este analisis en la aplicacion de escritorio jamovi:Haga clic en el menu [menu_path].Arrastre las variables [vars] al panel de [label_vars].(Opcional) Configure [label_param] activando la opcion [value]."4. Implementacion en server.pyCada respuesta exitosa de una herramienta estadistica debe incluir un campo gui_instructions generado dinamicamente por este motor.
